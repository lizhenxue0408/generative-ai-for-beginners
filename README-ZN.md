# Generative AI for Beginners（第 3 版）—— 一门课程

通过微软云倡导者（Microsoft Cloud Advocates）提供的这门 21 课综合课程，学习构建生成式 AI 应用的基础知识。

## 🌱 入门

本课程包含 21 节课。每节课涵盖一个独立的主题，你可以从任意感兴趣的地方开始！

课程分为 "Learn"（学习）类和 "Build"（构建）类：前者讲解生成式 AI 概念，后者在可能的情况下通过 **Python** 和 **TypeScript** 代码讲解概念与示例。

.NET 开发者请查看 [Generative AI for Beginners (.NET Edition)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst)！

每节课还包含一个 "Keep Learning"（持续学习）小节，提供额外的学习资源。

## 你需要准备什么

### 要运行本课程的代码，你可以使用以下任一服务：
 - [Azure OpenAI Service](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) - **对应课程：** "aoai-assignment"
 - [Microsoft Foundry Models](https://ai.azure.com/catalog/models?WT.mc_id=academic-105485-koreyst) - **对应课程：** "githubmodels"（GitHub Models 将于 2026 年 7 月底停用——请改用 Microsoft Foundry Models）
 - [OpenAI API](https://aka.ms/genai-beginners/open-ai?WT.mc_id=academic-105485-koreyst) - **对应课程：** "oai-assignment"
 - [Foundry Local](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) - 在你的设备上完全离线运行模型，无需云订阅

- 具备 Python 或 TypeScript 的基础知识会很有帮助 - \*绝对初学者请查看这些 [Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) 和 [TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst) 课程
- 一个 GitHub 账户，用于将[整个仓库 fork](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst) 到你自己的 GitHub 账户

我们创建了一节 **[课程安装（Course Setup）](./00-course-setup/README.md?WT.mc_id=academic-105485-koreyst)** 来帮助你配置开发环境。

别忘了[为这个仓库点星（🌟）](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst)，以便日后更容易找到它。
